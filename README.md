# New-cat-miniapp

微信小程序项目，当前已整理为独立维护版本。

## 本地启动

```bash
npm install
npm run dev:weapp
```

## 本地编译

```bash
npm run build:weapp
```

## 微信开发者工具

1. 打开微信开发者工具
2. 导入项目目录：`D:\\萌宠用药提醒网站\\0802 coedx\\New-cat-miniapp`
3. 选择编译目录：`dist/`
4. 确认 `project.config.json` 中的 AppID 已正确配置

## 目录说明

- `src/`：小程序源码
- `PAGE_STRUCTURE_V1.md`：页面结构与字段清单
- `PRD_v1.md`：产品说明文档
- `package-lock.json`：依赖锁文件
